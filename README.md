# 1950 — 운명의 한반도 (프로토타입 v0.2)

6·25 전쟁(1950.6.25~)을 배경으로 한 **턴제 국가전략 시뮬레이션**입니다.
삼국지 2식 "지역 내정 + 여단 운용"에 6·25 특유의 극적인 전황 변화를 얹었습니다. (플레이: 대한민국 / 상대: 북한군 AI)

## 실행 방법 (프로그래밍을 몰라도 됩니다)

1. [Node.js](https://nodejs.org) LTS 버전을 설치합니다. (이미 있으면 생략)
2. 이 폴더에서 터미널(Windows: PowerShell)을 열고 아래를 **한 번만** 실행합니다.
   ```
   npm install
   ```
3. 게임 실행:
   ```
   npm run dev
   ```
   터미널에 나오는 주소(보통 http://localhost:5173)를 브라우저(Chrome 권장)에서 엽니다.
4. 테스트: `npm test` / 빌드 검사: `npm run build` / 자동 플레이 시험(밸런스): `npm run sim`

## 조작
- 지도: 휠 확대·축소, 드래그 이동, 지역 클릭. 상단 좌측 버튼으로 통제/보급/안정도/지형 레이어 전환.
- 파란 원의 숫자 = **여단 수**(병력 규모 아님). 빨간 원 = 정찰된 적 여단 수, 점선 `?` = 정찰되지 않음(오래된 정보).
- 오른쪽 [부대] 탭: 부대 체크 → 이동/공격(지도에서 강조 지역 클릭)/방어선 강화/휴식/훈련. [내정] 탭: 징집·신병 훈련·여단 창설·보충·장비 생산/배분·복구·방어시설.
- 하단 [턴 종료]. 초반(6월)은 1턴 3일, 7월부터 7일. 메뉴에서 저장/불러오기/새 게임/재시작.

## v0.5 변경점 (총동원령·군수·사상자)
- **총동원령 이벤트**: 낙동강 방어선 형성 / 주요 전선 후퇴+후방 위협 / 대체역사 위기에서 별도 이벤트로 발생. 발동 즉시 국군 여단급 부대가 1:1로 사단급(기준 약 1만 명)으로 전환되고, 징병 가능 인구에서 긴급 동원병이 충원됩니다(부대 수·위치·이력 유지, 장비는 자동 생성되지 않음).
- **국가 단위 징집**: [국가 관리]에서 징집→훈련병 풀→보충/창설. 통제 지역의 남은 인구만 징병 자원이 됩니다(점령 직후 효율 제한).
- **군수 자동 생산·배분**: 산업 특성별 생산, 국가 재고, 부족 부대에 자동 배분(보급 단절 부대 제외).
- **사상자 구분**: 전사(영구)/부상(치료 후 복귀)/실종·포로, 부상병 자동 회복, 손상 장비 수리, 후퇴 경로가 없으면 전멸.
- **국가 사상자 보고** 이벤트, 부대 선택 [절반만 선택]·[휴식 필요 부대 선택], **전장의 안개 토글(기본 꺼짐)**.

## 데이터 출처 구분 (중요)
- **확인된 공식 수치는 없습니다.** 지역별 인구·산업·징집 인구는 "남한 약 2,000만 / 북한 약 950만"이라는 총량 추정에 가중치를 배분한 **추정치**이고, 산업력·전략가치·부대 능력치는 **게임 밸런스 수치**입니다. 각 프로빈스 `dataQuality` 필드에 표기되어 있습니다.
- 부대 편제·번호·배치는 근사입니다. 이벤트 중 `needsVerification: true` 항목은 국가기록원·군사편찬연구소 원자료와 대조 검증이 필요합니다.
- 이벤트 선택지 중 "가상의 선택"은 역사에서 실제로 선택되지 않은 대안입니다 (`isCounterfactual`).
